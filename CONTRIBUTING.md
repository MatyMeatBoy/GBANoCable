# Contributing to GBANoCable

Thank you! Useful contributions, in any language (English preferred for code and docs, Spanish welcome):

1. **Game notes**: document a game's link layer with [games/TEMPLATE.md](games/TEMPLATE.md). Addresses and
   behaviour only; never paste copyrighted game code or data.
2. **Hooks**: a working integration in a decompilation, recompilation or emulator (link to it; keep game-specific
   code in that project).
3. **Reference library**: N-player tests, rollback helpers, state hashing and repair, more transports
   (ICE/WebRTC, consoles).
4. **Tools**: ROM scanners that find SIO driver functions; trace comparers.
5. **Testing reports**: real matches across networks (which game, transports, delay, outages, what happened).

Rules: be kind, cite sources, keep the license (MIT) for what you write here, no ROMs, no game assets.
